# OSM Town Watch (バリアフリー情報可視化マップ)

OpenStreetMap（OSM）に登録されたバリアフリー情報（車椅子対応施設、エレベーター、多機能トイレ、縁石・段差、横断歩道など）の登録進捗と通行可否ステータスを可視化するWebマップアプリケーションです。

GitHub Actions による定期集計データ（`data/tiles.json`）を静的配信し、フロントエンド側で直接読み込む構成をとっています。

---

## 🌟 主な特徴

- **静的JSONファイルの非同期読み込み**
  - GitHub Actions が集計した `data/tiles.json` をブラウザ起動時に取得し、タイルヒートマップを初期描画します。
- **固定グリッド（Webメルカトル Zoom 16基準）による集計表示**
  - 地理座標に基づいた約600m四方の固定タイル単位で、候補地物数に対するバリアフリー情報付与率（%）と件数を集計・色分け表示します。
  - タイルには透過スタイルを適用し、下地となる地図の地名や道路線を表示します。
- **セッションストレージによる表示位置の保持**
  - 操作中の中心座標とズームレベルを `sessionStorage` に記録し、ページ再読み込み時にも直前の表示範囲を復元します。
- **最大ズーム（Zoom 19）における個別地物のオーバーレイ表示**
  - ズームレベル19到達時のみ、ヒートマップ上に個別地物のピンを表示します。
  - アイコンの形状（円／角丸四角）で登録有無を、背景色で通行可否を分類表示します。

---

## 🎨 表示仕様・凡例

### 1. タイルヒートマップ（Zoom 16 基準）
各タイル内の「対象地物総数」に対する「バリアフリー情報付与済み地物数」の割合（%）に応じて、以下の4段階で配色します。

| 付与率（%） | タイル色 | 状態 |
| :--- | :--- | :--- |
| **0% 〜 24%** | 赤（Red） | 付与率 低 |
| **25% 〜 49%** | 黄橙（Orange） | 付与率 中低 |
| **50% 〜 74%** | 黄緑（Light Green） | 付与率 中高 |
| **75% 〜 100%** | 緑（Green） | 付与率 高 |

各タイル中央のバッジには `[付与率%] [付与数 / 候補総数]` を表示します。

### 2. 個別ピン（Zoom 19 到達時）

アイコンの形状で登録状況を、背景色で通行可否を表します。

#### 【形状】登録状況
- **円形（実線白枠）**: **登録済み**（タグ値が設定されている地物）
- **四角形（破線枠）**: **未登録**（バリアフリー関連タグが未設定の候補地物）

#### 【色】通行状況
- **緑（Green）**: **通行可** (`wheelchair=yes`, `kerb=flush/lowered`, エレベーター等)
- **黄（Yellow）**: **要介助・条件付き** (`wheelchair=limited`, 車椅子対応トイレのみ等)
- **赤（Red）**: **通行不可** (`wheelchair=no`, `kerb=raised` 等)
- **灰（Gray）**: **未調査・詳細不明** (`wheelchair` 未設定、縁石の段差詳細未設定等)

#### 【ピクトグラム】地物分類
- `♿`: 車椅子対応施設・店舗・設備
- `🛗`: エレベーター (`highway=elevator`)
- `🚻`: 車椅子対応トイレ (`toilets:wheelchair=yes`)
- `⤓`: 縁石・歩道段差 (`barrier=kerb` / `kerb=*`)
- `🚶`: 横断歩道 (`highway=crossing`)
- `❓`: バリアフリー情報未登録の店舗・施設

## 🏗️ システム構成

```text
[定期実行 (GitHub Actions)]
        │
        ▼ Overpass API から対象エリアのデータを取得
scripts/aggregate_barrier.py
        │
        ▼ Zoom 16固定タイル単位で集計
data/tiles.json (リポジトリ内にコミット・プッシュ)
        │
        ▼ 静的ファイルとして配信
ブラウザ (index.html / Leaflet.js)
        ├── 起動時: ./data/tiles.json を読み込みヒートマップを描画
        └── Zoom 19: 表示範囲の詳細データを Overpass API から取得してピン描画
